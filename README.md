# the agent builds a game from one prompt

One prompt, one AI agent, one playable game. The prompt (kept verbatim in `PROMPT.txt`) asked for a neon browser game where a glowing orb speeds down an endless corridor and the player presses one button to flip gravity between the floor and the ceiling, dodging jagged crystal shards and collecting stars until a single crash ends the run. The agent built exactly that as **GRAVITY FLIP** — a single self-contained HTML file under `game/` (no dependencies, no network), filmed itself being built and played, and the clip was posted on X with make.fun's referral end card. `POST.json` holds the post's address; `main.ts` copies it to the output directory.
